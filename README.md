# Tiptap Editor Setup

A rich text editor setup for Next.js projects using Tiptap.

## Installation

```
npm install @pratush26/tiptap-rte
```
1. In the root layout.tsx import this
```
import "@pratush26/tiptap-rte/styles.css"
```
2. Where you want to use the editor, import like this
```
import { SimpleEditor } from "@pratush26/tiptap-rte"
```
3. Where you want to preview the editor data, import like this
```
import { SimpleEditorPreview } from "@pratush26/tiptap-rte"
```
4. If you want to use image uploader, then setup a api route /api/upload
